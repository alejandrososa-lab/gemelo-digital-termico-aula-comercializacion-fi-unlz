
# Gemelo Digital del Aula

Prototipo didáctico en Python + Streamlit.

## Qué permite hacer

- Cambiar cantidad de alumnos.
- Cambiar temperatura exterior e interior.
- Cambiar potencia del aire acondicionado.
- Abrir/cerrar persianas.
- Modificar radiación solar.
- Ver la evolución simulada de la temperatura.
- Comparar escenarios "¿qué pasaría si...?".

## Cómo ejecutarlo

1. Instalar Python 3.10 o superior.
2. Abrir una terminal en esta carpeta.
3. Ejecutar:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Se abrirá una página en el navegador.

## Uso didáctico

La idea es mostrar:

**Realidad → Datos → Modelo digital → Simulación → Decisión**

Este modelo es deliberadamente simplificado y no debe usarse para dimensionamiento profesional de HVAC.
